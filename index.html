Firebase 설정이 필요해요

이 사이트는 참가자들 사이에 대진표를 실시간으로 동기화하기 위해 무료 Firebase Realtime Database를 사용합니다. 아래 순서대로 index.html 파일 상단의 firebaseConfig 값을 채워주세요.

  1. Firebase 콘솔에서 새 프로젝트를 만듭니다 (무료 Spark 요금제, 카드 등록 불필요).
  2. 왼쪽 메뉴 Build → Realtime Database로 이동해 데이터베이스를 만듭니다. (위치는 아무 곳이나 선택)
  3. 규칙(Rules) 탭에서 아래 내용으로 바꾸고 게시합니다: 
    {
  "rules": {
    "brackets": {
      "$code": { ".read": true, ".write": true }
    },
    "$other": { ".read": false, ".write": false }
  }
}
  4. 프로젝트 개요(톱니바퀴 아이콘) → 프로젝트 설정 → 내 앱에서 웹 앱(</>)을 추가합니다.
  5. 표시되는 firebaseConfig 객체 전체를 복사해, 이 파일 상단 firebaseConfig 자리에 붙여넣습니다.
  6. 파일을 저장하고 새로고침하면 바로 사용할 수 있어요.
